About this website

Surf Fishin' Time combines shoreline, weather, tide, and moon information for a selected station and date, then asks an OpenAI agent to provide an overall fishing recommendation.

How it works

This page is served by a Python FastAPI application. The browser calls the app's /api/states and /api/cities endpoints to populate the station selectors, then requests /forecast/get_forecast for the selected station and date. The backend assembles the provider data and returns it to the page for display and submits to OpenAI for fishing outlook generation.

External APIs

  • NOAA Tides & Currents provides tide-prediction station metadata and tide predictions.
  • The National Weather Service API provides local forecast grid data and forecast periods.
  • Open-Meteo's geocoding API resolves city names to coordinates and time zones.
  • The U.S. Naval Observatory API provides moon-phase data.
  • The OpenAI API runs the configured agent to generate a fishing recommendation from the assembled conditions.

AWS services

  • Amazon ECS with AWS Fargate: Runs the containerized Python backend without requiring server management.
  • Amazon ECR: Stores Docker images used to deploy the backend.
  • Application Load Balancer: Routes incoming HTTP requests to the backend service.
  • AWS Secrets Manager: Securely stores the OpenAI API key.
  • Amazon CloudWatch: Collects application logs for monitoring and troubleshooting.
  • AWS IAM: Manage roles and permissions
  • VPC and security groups: Manage permissions and network access.
